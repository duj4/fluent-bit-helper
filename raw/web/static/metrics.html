How to export JSON

Download Mimirtool for your operating system and architecture, make it executable and available on your PATH. On a Linux amd64 machine that can access Grafana, run:

mimirtool-linux-amd64 analyze grafana \
  --address="https://<grafana-host>" \
  --key="<GRAFANA_TOKEN>" \
  --output="<your-filename>.json"

Replace the Grafana URL with the actual address for your environment and the API token placeholder with your token. HTTPS uses port 443 by default; no port is needed in the URL. For a non-standard port, append :<port> to the Grafana host. Choose your own output filename in --output, then upload the generated JSON using the Dashboard JSON control above. For other platforms, use the corresponding Mimirtool executable name.

{
  "metricsUsed": ["metric_a"],
  "dashboards": [{
    "uid": "example-dashboard", "title": "Example Dashboard",
    "metrics": ["metric_a"]
  }]
}

Each dashboard must include its own metric list. The global metricsUsed list does not replace per-dashboard metrics.

How to export JSON 
curl -fsS \
  -H 'Authorization: Bearer <token>' \
  'https://<grafana_host>/api/v1/provisioning/alert-rules' \
  -o alert-rules.json

Export Grafana-managed Alert Rules as JSON. Do not append /export to the API endpoint.

Run export commands locally with a read-only token. Keep real tokens out of shared logs and command history. -fsS checks HTTP errors and shows failures in silent mode.

Upload either file or both. JSON only, up to 8 MiB each. No API token is needed and this service does not connect to Grafana. Files are analyzed in server memory; dashboards, alerts and queries are never automatically modified.
