How to export JSON

Download Mimirtool for Windows (x64) on your Windows laptop that can access your Production Grafana. You do not need to log in to the Production server. From the folder containing the executable, run either command:

PowerShell

.\mimirtool-windows-amd64.exe analyze grafana `
  --address="https://<grafana-host>" `
  --key="<GRAFANA_TOKEN>" `
  --output="<your-filename>.json"

CMD

mimirtool-windows-amd64.exe analyze grafana ^
  --address="https://<grafana-host>" ^
  --key="<GRAFANA_TOKEN>" ^
  --output="<your-filename>.json"

Choose your own output filename in --output, then upload the generated JSON using the Dashboard JSON control above.

{
  "metricsUsed": ["metric_a"],
  "dashboards": [{
    "uid": "example-dashboard", "title": "Example Dashboard",
    "metrics": ["metric_a"]
  }]
}

Each dashboard must include its own metric list. The global metricsUsed list does not replace per-dashboard metrics.

How to export JSON

On your Windows laptop that can access Grafana, run either command to export Grafana-managed Alert Rules as JSON. No Production server login is required.

PowerShell

curl.exe -fsS `
  -H "Authorization: Bearer <GRAFANA_TOKEN>" `
  "https://<grafana-host>/api/v1/provisioning/alert-rules" `
  -o "<your-filename>.json"

CMD

curl.exe -fsS ^
  -H "Authorization: Bearer <GRAFANA_TOKEN>" ^
  "https://<grafana-host>/api/v1/provisioning/alert-rules" ^
  -o "<your-filename>.json"

Choose your own output filename with -o, then upload the generated JSON using the Alert Rule JSON control above. Do not append /export to the API endpoint.

Run export commands locally with a read-only token. Keep real tokens out of shared logs and command history. -fsS checks HTTP errors and shows failures in silent mode.

Upload either file or both. JSON only, up to 8 MiB each. No API token is needed and this service does not connect to Grafana. Files are analyzed in server memory; dashboards, alerts and queries are never automatically modified.
