Upload your Grafana exports

How to export JSON 
curl -fsS \
  -H 'Authorization: Bearer <token>' \
  'https://<grafana_host>/apis/dashboard.grafana.app/v1/namespaces/org-<org_id>/dashboards' \
  -o dashboards.json

Replace <org_id> with your Grafana Organization ID. For the default organization (Org ID 1), use default instead of org-<org_id>.

How to export JSON 
curl -fsS \
  -H 'Authorization: Bearer <token>' \
  'https://<grafana_host>/api/v1/provisioning/alert-rules' \
  -o alert-rules.json

Export Grafana-managed Alert Rules as JSON. Do not append /export to the API endpoint.

Run export commands locally with a read-only token. Keep real tokens out of shared logs and command history. -fsS checks HTTP errors and shows failures in silent mode.

Upload either file or both. JSON only, up to 8 MiB each. No API token is needed and this service does not connect to Grafana. Files are analyzed in server memory; dashboards, alerts and queries are never automatically modified.

Choose at least one JSON file to begin.
