Label guidance

Loki labels are indexed and used to select log streams. filename and instance are always included.

Add only stable, low-cardinality fields such as level, service, or component.

Avoid unique or high-cardinality fields such as timestamp, message, trace_id, request_id, or user_id.

Additional Loki labels

Structured metadata guidance

Structured metadata is attached to each log line but is not indexed by Loki.

Recommended for searchable high-cardinality fields such as trace_id, request_id, correlation_id, thread, or user_id.
